CZYM JEST ALGORYTM ZACHŁANNY?

Algorytm zachłanny charakteryzuje się tym, że w celu wyznaczenia rozwiązania w każdym kroku dokonuje zachłannego, tj. najlepszego w danym momencie wyboru, wyboru rozwiązania podproblemu. Nie cofa podjętych wcześniej decyzji, lecz wybiera lokalnie najkorzystniejszą opcję.

Odpowiedź na pytanie z zadania:

  • Dla reszty 6: Algorytm najpierw wybiera największą możliwą monetę ≤ 6, czyli 5 (zostaje 6 - 5 = 1), a następnie monetę 1 (zostaje 1 - 1 = 0). Rozwiązanie to 2 monety: 5 oraz 1.
  • Dla reszty 13: Algorytm wybiera kolejno: 5 (zostaje 13 - 5 = 8), znów 5 (zostaje 8 - 5 = 3), następnie 2 (zostaje 3 - 2 = 1) oraz 1 (zostaje 1 - 1 = 0). Rozwiązanie to 4 monety: 5, 5, 2 oraz 1.

Interaktywny symulator wydawania reszty (nominały: 5, 2, 1)

1. Algorytm opisowy (lista kroków)

Specyfikacja problemu oraz słowny zapis kolejnych kroków
Typ 1: Opisowy

Specyfikacja zadania:

  • Dane wejściowe: Liczba całkowita dodatnia R oznaczająca kwotę reszty do wydania (R > 0) oraz uporządkowana malejąco tablica dostępnych nominałów monet M = [5, 2, 1].
  • Wynik: Wykaz wydanych monet (oraz ich łączna liczba), których suma jest równa R, przy użyciu minimalnej liczby monet.

Lista kroków algorytmu:

  1. Wczytaj kwotę reszty do wydania R oraz przygotuj tablicę dostępnych nominałów uporządkowaną malejąco: M = [5, 2, 1].
  2. Ustaw licznik wydanych monet liczba_monet := 0 oraz indeks aktualnie rozpatrywanego nominału i := 0 (zaczynamy od największego nominału, czyli 5).
  3. Dopóki pozostała kwota reszty R > 0, wykonuj kroki 4–5. Gdy R = 0, przejdź do kroku 6.
  4. Sprawdź, czy aktualny nominał mieści się w pozostałej reszcie (czy R ≥ M[i]):
    – Jeśli TAK: wydaj monetę o nominale M[i], zmniejsz pozostałą resztę o wartość tej monety (R := R - M[i]) i zwiększ licznik wydanych monet o 1 (liczba_monet := liczba_monet + 1).
    – Jeśli NIE: przejdź do kolejnego, mniejszego nominału, zwiększając indeks o 1 (i := i + 1).
  5. Wróć do sprawdzenia warunku pętli w kroku 3.
  6. Wypisz wszystkie wydane monety oraz ich łączną liczbę liczba_monet i zakończ działanie algorytmu.

2. Pseudokod

Formalny zapis algorytmu zachłannego wydawania reszty
Typ 2: Pseudokod

Wersja A (odejmowanie pojedynczych monet) oraz Wersja B (z dzieleniem całkowitym div / mod):

W zapisie pseudokodu możemy odejmować nominał w pętli tak długo, aż reszta spadnie poniżej wartości monety, lub od razu wyznaczyć krotność monety operacją dzielenia całkowitego div:

Algorytm WydawanieReszty(R)
    Dane:
        R — kwota reszty do wydania (liczba całkowita dodatnia)
        M[1..3] = [5, 2, 1] — tablica nominałów uporządkowana malejąco
    Wynik:
        Wypisane nominały wydanych monet oraz ich łączna liczba

Początek
    liczba_monet := 0
    i := 1

    dopóki R > 0 wykonuj
        jeżeli R >= M[i] to
            wypisz M[i]
            R := R - M[i]
            liczba_monet := liczba_monet + 1
        w przeciwnym razie
            i := i + 1

    wypisz "Liczba monet: ", liczba_monet
Koniec
Algorytm WydawanieResztyOptymalny(R)
    Dane:
        R — kwota reszty do wydania (liczba całkowita dodatnia)
        M[1..3] = [5, 2, 1] — tablica nominałów uporządkowana malejąco
    Wynik:
        Krotności poszczególnych nominałów oraz łączna liczba monet

Początek
    liczba_monet := 0
    i := 1

    dopóki R > 0 wykonuj
        jeżeli R >= M[i] to
            ile := R div M[i]
            wypisz "Nominał ", M[i], " x ", ile
            R := R mod M[i]
            liczba_monet := liczba_monet + ile
        i := i + 1

    wypisz "Łączna liczba monet: ", liczba_monet

3. Implementacja w C++, C# oraz Pythonie

Gotowe programy obliczające wydawanie reszty dla 6, 13 oraz dowolnej kwoty
Typ 3 i 4: C++ / C#

Porównanie implementacji:

Poniżej znajdują się kompletne programy w językach C++ oraz C# (a także w Pythonie do przetestowania na żywo w przeglądarce). Każdy program realizuje algorytm zachłanny dla nominałów {5, 2, 1} i prezentuje rozwiązanie dla reszty 6 oraz 13.

Złożoność czasowa: O(k), gdzie k to liczba dostępnych nominałów (przy użyciu dzielenia) lub O(R) (przy odejmowaniu pojedynczych monet)
Złożoność pamięciowa: O(1) dodatkowej pamięci.
#include <iostream>

using namespace std;

void wydajReszte(int kwota)
{
    int nominaly[3] = {5, 2, 1};
    int liczbaMonet = 0;
    int pozostalo = kwota;
    int i = 0;

    cout << "Reszta do wydania: " << kwota << endl;
    cout << "Wydane monety: ";

    while (pozostalo > 0 && i < 3)
    {
        if (pozostalo >= nominaly[i])
        {
            int ile = pozostalo / nominaly[i];
            for (int j = 0; j < ile; j++)
            {
                cout << nominaly[i] << " ";
            }
            pozostalo = pozostalo % nominaly[i];
            liczbaMonet += ile;
        }
        i++;
    }

    cout << "\nLaczna liczba monet: " << liczbaMonet << "\n" << endl;
}

int main()
{
    // Rozwiazanie dla reszty 6 oraz 13
    wydajReszte(6);
    wydajReszte(13);

    return 0;
}
using System;

class Program
{
    static void WydajReszte(int kwota)
    {
        int[] nominaly = { 5, 2, 1 };
        int liczbaMonet = 0;
        int pozostalo = kwota;
        int i = 0;

        Console.WriteLine($"Reszta do wydania: {kwota}");
        Console.Write("Wydane monety: ");

        while (pozostalo > 0 && i < nominaly.Length)
        {
            if (pozostalo >= nominaly[i])
            {
                int ile = pozostalo / nominaly[i];
                for (int j = 0; j < ile; j++)
                {
                    Console.Write(nominaly[i] + " ");
                }
                pozostalo = pozostalo % nominaly[i];
                liczbaMonet += ile;
            }
            i++;
        }

        Console.WriteLine($"\nŁączna liczba monet: {liczbaMonet}\n");
    }

    static void Main(string[] args)
    {
        // Rozwiązanie dla reszty 6 oraz 13
        WydajReszte(6);
        WydajReszte(13);
    }
}
def wydaj_reszte(kwota, nominaly=[5, 2, 1]):
    wydane_monety = []
    pozostalo = kwota
    i = 0

    while pozostalo > 0 and i < len(nominaly):
        if pozostalo >= nominaly[i]:
            ile = pozostalo // nominaly[i]
            for _ in range(ile):
                wydane_monety.append(nominaly[i])
            pozostalo = pozostalo % nominaly[i]
        i += 1

    return wydane_monety

for kwota in [6, 13]:
    monety = wydaj_reszte(kwota)
    print(f"Reszta {kwota}: monety {monety} -> {len(monety)} szt.")
