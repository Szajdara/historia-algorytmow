1. Zamiana liczby dziesiętnej na dwójkową

Konwersja między systemami pozycyjnymi
Strona 50, Ćwiczenie 1

Treść zadania z podręcznika:

„Napisz program, który po podaniu liczby całkowitej dodatniej wyświetli jej reprezentację binarną. Sprawdź działanie programu dla różnych liczb.”

Jak działa algorytm?

Algorytm opiera się na powtarzanym dzieleniu całkowitym wczytanej liczby dziesiętnej przez podstawę systemu docelowego (czyli 2) oraz zapamiętywaniu reszt z dzielenia:

  • Wyznaczanie bitu: W każdej iteracji pętli obliczamy resztę z dzielenia liczby przez 2 (operacja d % 2). Jeśli reszta wynosi 0, bitem jest znak '0'; jeśli 1 – znak '1'.
  • Kolejność bitów: Pierwsza obliczona reszta to najmniej znaczący bit (po prawej stronie zapisu binarnego). Dlatego kolejno uzyskiwane cyfry dołączamy na początek budowanego napisu (b = cyfra + b).
  • Zmniejszanie liczby: Po wyznaczeniu cyfry dzielimy liczbę całkowitoliczbowo przez 2 (d = d / 2).
  • Warunek stopu: Pętla wykonuje się dopóki liczba jest większa od 0 (while (d > 0)). Dla liczby 26 otrzymujemy kolejno reszty 0, 1, 0, 1, 1, co po dołączaniu od lewej daje poprawny wynik 11010.
Złożoność czasowa: $O(\log_2 n)$ operacji (tyle ile bitów ma liczba)
Złożoność pamięciowa: $O(\log_2 n)$ na łańcuch znaków.
#include <iostream>
#include <string>

using namespace std;

int main()
{
    int d;
    string b = "";
    cout << "Podaj liczbe dziesietna: ";
    cin >> d;
    while (d > 0)
    {
        if (d % 2 == 0)
            b = '0' + b;
        else
            b = '1' + b;
        d = d / 2;
    }
    cout << "Liczba binarna: " << b << endl;
    return 0;
}
def dec_to_bin(d):
    if d == 0:
        return "0"
    b = ""
    liczba = d
    while liczba > 0:
        if liczba % 2 == 0:
            b = "0" + b
        else:
            b = "1" + b
        liczba = liczba // 2
    return b

liczba = 26
print(f"Liczba {liczba} w systemie dwojkowym to: {dec_to_bin(liczba)}")

2. Szybkie podnoszenie do potęgi

Potęgowanie binarne (algorytm logarytmiczny)
Strona 58, Ćwiczenie 7

Treść zadania z podręcznika:

„Napisz i przetestuj program szybkiego podnoszenia do potęgi. Dobieraj dane tak, aby nie przekroczyć zakresu wyniku.”

Jak działa algorytm?

Zamiast wykonywać naiwne mnożenie podstawy $x$ przez samą siebie $n$ razy (co wymaga $O(n)$ mnożeń), algorytm korzysta z binarnego zapisu wykładnika:

  • Reprezentacja binarna wykładnika: Każdą potęgę $x^n$ możemy zapisać jako iloczyn potęg o wykładnikach będących potęgami dwójki, np. $x^{13} = x^{8 + 4 + 1} = x^8 \cdot x^4 \cdot x^1$.
  • Podwajanie czynnika: Zmienna pomocnicza tmp przechowuje kolejne kwadraty podstawy ($x, x^2, x^4, x^8, \dots$). Podnosimy ją do kwadratu w każdym kroku (tmp = tmp * tmp).
  • Sprawdzanie bitu: Badamy najmłodszy bit wykładnika: jeśli n % 2 == 1, to mnożymy dotychczasowy wynik y przez bieżącą wartość tmp.
  • Skracanie wykładnika: Dzielimy wykładnik całkowitoliczbowo przez 2 (n = n / 2). W ten sposób dla $n = 1000$ wykonujemy zaledwie ok. 10 mnożeń zamiast tysiąca!
Złożoność czasowa: $O(\log_2 n)$ mnożeń
Złożoność pamięciowa: $O(1)$ (stała pamięć pomocnicza).
#include <iostream>

using namespace std;

int main()
{
    int x, n;
    long long y, tmp;
    cout << "Podaj podstawe potegi: ";
    cin >> x;
    cout << "Podaj wykladnik potegi: ";
    cin >> n;
    tmp = x;
    y = 1;
    while (n > 0)
    {
        if (n % 2 == 1)
            y = y * tmp;
        n = n / 2;
        if (n > 0)
            tmp = tmp * tmp;
    }
    cout << "Wartosc potegi: " << y << endl;
    return 0;
}
def szybkie_potegowanie(x, n):
    y = 1
    tmp = x
    wykladnik = n
    while wykladnik > 0:
        if wykladnik % 2 == 1:
            y = y * tmp
        wykladnik = wykladnik // 2
        if wykladnik > 0:
            tmp = tmp * tmp
    return y

przyklady = [(3, 13), (2, 10), (5, 4), (7, 5)]
for podstawa, wykladnik in przyklady:
    wynik = szybkie_potegowanie(podstawa, wykladnik)
    print(f"{podstawa}^{wykladnik} = {wynik}")

3. Sprawdzanie, czy wyraz jest palindromem

Analiza łańcuchów znaków i technika dwóch wskaźników
Strona 63, Ćwiczenie 1

Treść zadania z podręcznika:

„a. Napisz program sprawdzający, czy wyraz złożony z małych liter alfabetu łacińskiego jest palindromem.
b. Zmodyfikuj specyfikację oraz program sprawdzający, czy wyraz jest palindromem, w taki sposób, aby wypisywał słowo «TAK» niezależnie od tego, czy do zapisu wyrazu użyto małych czy wielkich liter.”

Jak działa algorytm?

Palindrom to słowo brzmiące identycznie czytane wprost i wspak (np. „kajak”, „radar”, „Anna”):

  • Dwa wskaźniki: Ustawiamy indeks i = 0 na początku wyrazu oraz indeks j = n - 1 na ostatnim znaku słowa.
  • Ignorowanie wielkości liter: Przed porównaniem znaki zamieniamy na małe litery za pomocą funkcji tolower() w C++ lub lower() w Pythonie, dzięki czemu np. litery 'K' i 'k' są uznawane za zgodne.
  • Porównanie i zbieżność: W pętli sprawdzamy, czy znak po lewej równa się znakowi po prawej. Jeśli tak, przesuwamy wskaźniki ku środkowi: i++ oraz j--.
  • Wczesne zakończenie: Gdy natrafimy na niezgodność, natychmiast zmieniamy flagę na false i przerywamy pętlę. Sprawdzamy co najwyżej $n/2$ par liter.
Złożoność czasowa: $O(n)$ (dokładnie $\le n/2$ porównań)
Złożoność pamięciowa: $O(1)$ dodatkowej pamięci.
#include <iostream>
#include <string>
#include <cctype>

using namespace std;

int main()
{
    string wyraz;
    int i = 0, j;
    bool palindrom = true;
    cout << "Podaj wyraz: ";
    cin >> wyraz;
    j = wyraz.size() - 1;
    while (palindrom && i < j)
    {
        if (tolower(wyraz[i]) == tolower(wyraz[j]))
        {
            i++;
            j--;
        }
        else
            palindrom = false;
    }
    if (palindrom)
        cout << "TAK" << endl;
    else
        cout << "NIE" << endl;
    return 0;
}
def czy_palindrom(wyraz):
    s = wyraz.lower()
    i = 0
    j = len(s) - 1
    palindrom = True
    while palindrom and i < j:
        if s[i] == s[j]:
            i += 1
            j -= 1
        else:
            palindrom = False
    return palindrom

slowo = "Kajak"
odpowiedz = "TAK" if czy_palindrom(slowo) else "NIE"
print(f"Czy slowo '{slowo}' jest palindromem? {odpowiedz}")

4. Test pierwszości liczby

Poszukiwanie dzielników w postaci 6i ± 1
Strona 78, Ćwiczenie 2

Treść zadania z podręcznika:

„Napisz i przetestuj program sprawdzający, czy podana liczba jest pierwsza. Wykorzystaj w nim poszukiwanie dzielników wśród liczb o postaci 6i – 1 oraz 6i + 1.”

Jak działa algorytm?

Liczba pierwsza ma dokładnie dwa dzielniki naturalne: 1 i samą siebie. Zamiast sprawdzać wszystkie dzielniki do $n$, stosujemy matematyczne optymalizacje:

  • Warunek pierwiastka: Jeśli liczba $n$ ma dzielnik większy od $\sqrt{n}$, to musi mieć odpowiadający mu dzielnik mniejszy od $\sqrt{n}$. Wystarczy badać dzielniki do warunku $d^2 \le n$.
  • Eliminacja liczb parzystych i podzielnych przez 3: Na początku sprawdzamy podzielność przez 2 oraz 3. Dzięki temu eliminujemy $\frac{2}{3}$ wszystkich kolejnych liczb!
  • Własność liczb pierwszych ($6i \pm 1$): Każda kolejna liczba pierwsza większa od 3 musi dawać przy dzieleniu przez 6 resztę 1 lub 5 (czyli ma postać $6i - 1$ lub $6i + 1$).
  • Skok co 6: Zmienna d zaczyna od 5. W pętli sprawdzamy d oraz d + 2 (np. 5 i 7, potem 11 i 13, 17 i 19), zwiększając d o 6 (d = d + 6). Drastycznie skraca to liczbę operacji.
Złożoność czasowa: $O(\sqrt{n} / 3)$
Złożoność pamięciowa: $O(1)$.
#include <iostream>

using namespace std;

int main()
{
    int n, d = 5;
    bool pierwsza;
    cout << "n = ";
    cin >> n;
    pierwsza = (n > 1);
    if (n > 2 && n % 2 == 0) pierwsza = false;
    if (n > 3 && n % 3 == 0) pierwsza = false;
    while (pierwsza && (d * d <= n))
    {
        if (n % d == 0)
            pierwsza = false;
        else if (n % (d + 2) == 0)
            pierwsza = false;
        else
            d = d + 6;
    }
    if (pierwsza)
        cout << "TAK" << endl;
    else
        cout << "NIE" << endl;
    return 0;
}
def czy_pierwsza(n):
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    d = 5
    while d * d <= n:
        if n % d == 0 or n % (d + 2) == 0:
            return False
        d += 6
    return True

liczba = 37
wynik = "PIERWSZA" if czy_pierwsza(liczba) else "ZLOZONA"
print(f"Liczba {liczba} jest: {wynik}")

5. Rozkład liczby na czynniki pierwsze

Faktoryzacja z optymalizacją podwójnego kroku
Strona 81, Ćwiczenie 4

Treść zadania z podręcznika:

„Program wypisujący czynniki pierwsze podanej liczby naturalnej zmodyfikuj tak, aby ewentualny czynnik pierwszy 2 rozpatrzyć w oddzielnej pętli, a w pętli głównej powiększać wartość zmiennej d o 2.”

Jak działa algorytm?

Zgodnie z zasadniczym twierdzeniem arytmetyki, każdą liczbę naturalną większą od 1 można jednoznacznie przedstawić w postaci iloczynu liczb pierwszych:

  • Wydzielenie dwójki: Jedyną parzystą liczbą pierwszą jest 2. W osobnej początkowej pętli while (n % 2 == 0) dzielimy liczbę przez 2 i wypisujemy ten czynnik tak długo, jak jest to możliwe.
  • Badanie liczb nieparzystych: Po usunięciu wszystkich dwójek w liczbie nie ma już żadnych czynników parzystych! Zmienna d zaczyna od 3 i zwiększa się o 2 (d += 2), sprawdzając 3, 5, 7, 9, itd.
  • Warunek zakończenia pętli: Podobnie jak w teście pierwszości, wystarczy sprawdzać dzielniki do $d^2 \le n$.
  • Ostatni czynnik: Jeśli po wyjściu z pętli pozostała wartość $n > 1$, oznacza to, że pozostała część liczby jest już liczbą pierwszą i wypisujemy ją jako ostatni czynnik.
Złożoność czasowa: $O(\sqrt{n})$ operacji w najgorszym razie
Złożoność pamięciowa: $O(1)$.
#include <iostream>

using namespace std;

int main()
{
    int n, d = 2;
    cout << "n = ";
    cin >> n;
    cout << n << " = ";

    // Wydzielenie czynnika 2 w osobnej petli
    while (n % 2 == 0)
    {
        cout << 2 << " * ";
        n = n / 2;
    }

    // Czynniki nieparzyste z krokiem d += 2
    d = 3;
    while (d * d <= n)
    {
        if (n % d == 0)
        {
            cout << d << " * ";
            n = n / d;
        }
        else
            d += 2;
    }
    if (n > 1)
        cout << n;
    cout << endl;
    return 0;
}
def rozklad_na_czynniki_pierwsze(n):
    czynniki = []
    liczba = n
    while liczba % 2 == 0:
        czynniki.append(2)
        liczba = liczba // 2
    d = 3
    while d * d <= liczba:
        if liczba % d == 0:
            czynniki.append(d)
            liczba = liczba // d
        else:
            d += 2
    if liczba > 1:
        czynniki.append(liczba)
    return czynniki

liczba = 456
czynniki = rozklad_na_czynniki_pierwsze(liczba)
print(f"{liczba} = {' * '.join(map(str, czynniki))}")

6. Algorytm Euklidesa (NWD z dzieleniem)

Wyznaczanie największego wspólnego dzielnika
Strona 108, Ćwiczenie 1

Treść zadania z podręcznika:

„Napisz program wyznaczający największy wspólny dzielnik dwóch wczytanych liczb zgodnie z podanymi wcześniej specyfikacją i algorytmem [z wykorzystaniem reszty z dzielenia modulo].”

Jak działa algorytm?

Wersja algorytmu Euklidesa z operacją dzielenia modulo zastępuje powolne wielokrotne odejmowanie błyskawicznym dzieleniem z resztą:

  • Twierdzenie Euklidesa: Dla dowolnych dwóch liczb całkowitych dodatnich $a$ i $b$ zachodzi równość: $\text{NWD}(a, b) = \text{NWD}(b, a \bmod b)$.
  • Pętla redukcji: Dopóki druga liczba $b \neq 0$, wyznaczamy resztę $a \bmod b$. Nową wartością zmiennej $a$ staje się dotychczasowe $b$, a nową wartością $b$ – obliczona reszta.
  • Warunek zakończenia: Gdy reszta osiąga 0 (czyli $b = 0$), pętla kończy bieg, a szukanym Największym Wspólnym Dzielnikiem jest aktualna wartość zmiennej $a$.
  • Prędkość: Algorytm działa błyskawicznie nawet dla liczb mających setki cyfr. Np. dla liczb 1989 i 867 wynik 51 otrzymujemy w zaledwie 4 krokach!
Złożoność czasowa: $O(\log(\min(a, b)))$ (zgodna z twierdzeniem Lamé)
Złożoność pamięciowa: $O(1)$.
#include <iostream>

using namespace std;

int NWD(int a, int b)
{
    int pom;
    while (b != 0)
    {
        pom = b;
        b = a % b;
        a = pom;
    }
    return a;
}

int main()
{
    int a, b;
    cout << "a = "; cin >> a;
    cout << "b = "; cin >> b;
    cout << "NWD(" << a << ", " << b << ") = " << NWD(a, b) << endl;
    return 0;
}
def nwd_dzielenie(a, b):
    while b != 0:
        pom = b
        b = a % b
        a = pom
    return a

a = 1989
b = 867
print(f"NWD({a}, {b}) = {nwd_dzielenie(a, b)}")

7. Szyfrowanie szyfrem Cezara

Kryptografia klasyczna i arytmetyka modularna
Strona 120, Ćwiczenie 2

Treść zadania z podręcznika:

„Program szyfrujący napis złożony z wielkich liter alfabetu zmodyfikuj tak, aby przy wyznaczaniu litery szyfrogramu zastosować operację mod.”

Jak działa algorytm?

Szyfr Cezara polega na cyklicznym przesunięciu każdej litery alfabetu o stałą wartość $k$ (klucz):

  • Arytmetyka modularna: Alfabet łaciński ma 26 znaków (indeksy 0..25). Aby zapobiec wychodzeniu poza alfabet dla liter z końca (np. 'Z' + 3 = 'C'), stosujemy resztę z dzielenia przez 26.
  • Wzór matematyczny: Kod wynikowy litery wyznaczamy wzorem:
    nowy_znak = 'A' + (znak - 'A' + klucz) % 26.
  • Zachowanie znaków innych niż litery: Spacje, cyfry i znaki interpunkcyjne są przepisywane bez zmian.
  • Odszyfrowanie: Deszyfrowanie polega na przesunięciu w przeciwnym kierunku, czyli o klucz $26 - (k \bmod 26)$.
Złożoność czasowa: $O(n)$ dla tekstu o długości $n$
Złożoność pamięciowa: $O(n)$ na przechowanie szyfrogramu.
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string t_jawny, szyfrogram = "";
    int klucz;
    cout << "Tekst jawny: ";
    cin >> t_jawny;
    cout << "Klucz: ";
    cin >> klucz;
    
    for (int i = 0; i < t_jawny.size(); i++)
    {
        if (t_jawny[i] >= 'A' && t_jawny[i] <= 'Z')
        {
            char c = 'A' + (t_jawny[i] - 'A' + klucz) % 26;
            szyfrogram += c;
        }
        else if (t_jawny[i] >= 'a' && t_jawny[i] <= 'z')
        {
            char c = 'a' + (t_jawny[i] - 'a' + klucz) % 26;
            szyfrogram += c;
        }
        else
        {
            szyfrogram += t_jawny[i];
        }
    }
    cout << "Szyfrogram: " << szyfrogram << endl;
    return 0;
}
def szyfruj_cezar(tekst, klucz):
    szyfrogram = ""
    klucz = klucz % 26
    for c in tekst:
        if 'A' <= c <= 'Z':
            kod = (ord(c) - ord('A') + klucz) % 26 + ord('A')
            szyfrogram += chr(kod)
        elif 'a' <= c <= 'z':
            kod = (ord(c) - ord('a') + klucz) % 26 + ord('a')
            szyfrogram += chr(kod)
        else:
            szyfrogram += c
    return szyfrogram

jawny = "INFORMATYKA"
k = 3
print(f"Tekst jawny: '{jawny}' -> Zaszyfrowany: '{szyfruj_cezar(jawny, k)}'")

8. Wyszukiwanie binarne

Poszukiwanie elementu w uporządkowanej tablicy (dziel i zwyciężaj)
Strona 157, Ćwiczenie 3

Treść zadania z podręcznika:

„Napisz program, który sprawdzi, czy w uporządkowanej tablicy n liczb całkowitych występuje podany element. Liczbę powinna wyszukiwać funkcja realizująca algorytm przeszukiwania binarnego.”

Jak działa algorytm?

Wyszukiwanie binarne wymaga uprzednio posortowanego zbioru danych i realizuje technikę dziel i zwyciężaj:

  • Środek przedziału: Zamiast sprawdzać każdy element po kolei (co zajęłoby $O(n)$ w wyszukiwaniu liniowym), wyznaczamy element środkowy badanego przedziału srodek = (lewy + prawy) / 2.
  • Porównanie z celem: Jeśli szukana liczba $x$ jest równa elementowi środkowemu, kończymy z sukcesem.
  • Odrzucenie połowy zbioru: Jeśli szukana liczba jest mniejsza od środkowej, odrzucamy całą prawą połowę (prawy = srodek - 1); jeśli jest większa, odrzucamy całą lewą połowę (lewy = srodek + 1).
  • Potęga skali: W zbiorze 1 000 000 posortowanych elementów wyszukiwanie binarne znajdzie liczbę lub stwierdzi jej brak w maksymalnie 20 krokach!
Złożoność czasowa: $O(\log_2 n)$ operacji
Złożoność pamięciowa: $O(1)$ w wersji iteracyjnej.
#include <iostream>

using namespace std;

bool SzukajBin(int A[], int n, int x)
{
    int lewy = 0, prawy = n - 1, srodek;
    while (lewy <= prawy)
    {
        srodek = (lewy + prawy) / 2;
        if (A[srodek] == x)
            return true;
        else if (A[srodek] < x)
            lewy = srodek + 1;
        else
            prawy = srodek - 1;
    }
    return false;
}

int main()
{
    const int N = 9;
    int A[N] = {1, 4, 5, 6, 9, 12, 17, 24, 30};
    int x;
    cout << "Podaj liczbe do wyszukania: ";
    cin >> x;
    if (SzukajBin(A, N, x))
        cout << "Liczba jest w tablicy" << endl;
    else
        cout << "Liczby nie ma w tablicy" << endl;
    return 0;
}
def szukaj_bin(tablica, x):
    lewy = 0
    prawy = len(tablica) - 1
    while lewy <= prawy:
        srodek = (lewy + prawy) // 2
        if tablica[srodek] == x:
            return srodek
        elif tablica[srodek] < x:
            lewy = srodek + 1
        else:
            prawy = srodek - 1
    return -1

tab = [1, 4, 5, 6, 9, 12, 17, 24, 30]
szukana = 17
pozycja = szukaj_bin(tab, szukana)
print(f"Liczba {szukana} znaleziona na indeksie: {pozycja}")

9. Jednoczesne wyszukiwanie minimum i maksimum

Optymalny algorytm MiniMaks (porównania parami)
Strona 161, Ćwiczenie 4

Treść zadania z podręcznika:

„Napisz program wyszukujący jednocześnie największy i najmniejszy element tablicy. Wykorzystaj przedstawioną powyżej funkcję MiniMaks.”

Jak działa algorytm?

Naiwny algorytm wyszukiwania min i max wymaga $2n - 2$ porównań (przejście tablicy w poszukiwaniu minimum i drugie przejście w poszukiwaniu maksimum). Prezentowany algorytm oszczędza 25% operacji:

  • Grupowanie w pary: Pobieramy z tablicy po dwa sąsiednie elementy na raz: A[i] oraz A[i+1].
  • Pierwsze porównanie (wewnętrzne w parze): Porównujemy te dwa elementy ze sobą (1 operacja). Dzięki temu wiemy, który z nich jest lokalnym kandydatem na minimum, a który na maksimum.
  • Dwa porównania zewnętrzne: Element mniejszy z pary porównujemy wyłącznie z globalnym mini, a element większy z pary wyłącznie z globalnym maks.
  • Bilans zysku: Na każde dwa elementy tablicy zużywamy dokładnie 3 porównania zamiast 4. Łączna liczba porównań spada do $\approx \frac{3n}{2}$, co jest teoretycznym minimum dla tego problemu.
Złożoność: $\frac{3n}{2}$ porównań
Złożoność pamięciowa: $O(1)$.
#include <iostream>

using namespace std;

void MiniMaks(int A[], int n, int &mini, int &maks)
{
    if (A[0] > A[1])
    {
        mini = A[1]; maks = A[0];
    }
    else
    {
        mini = A[0]; maks = A[1];
    }
    for (int i = 2; i < n - 1; i += 2)
    {
        if (A[i] > A[i + 1])
        {
            if (A[i + 1] < mini) mini = A[i + 1];
            if (A[i] > maks) maks = A[i];
        }
        else
        {
            if (A[i] < mini) mini = A[i];
            if (A[i + 1] > maks) maks = A[i + 1];
        }
    }
}

int main()
{
    const int N = 8;
    int A[N] = {14, 3, 9, 27, 1, 42, 8, 19};
    int mini, maks;
    MiniMaks(A, N, mini, maks);
    cout << "MIN = " << mini << ", MAX = " << maks << endl;
    return 0;
}
def mini_maks(A):
    n = len(A)
    if n == 0: return None, None
    if n % 2 == 1:
        mini = maks = A[0]
        i = 1
    else:
        if A[0] > A[1]: mini, maks = A[1], A[0]
        else: mini, maks = A[0], A[1]
        i = 2
    while i < n - 1:
        if A[i] > A[i+1]:
            if A[i+1] < mini: mini = A[i+1]
            if A[i] > maks: maks = A[i]
        else:
            if A[i] < mini: mini = A[i]
            if A[i+1] > maks: maks = A[i+1]
        i += 2
    return mini, maks

dane = [14, 3, 9, 27, 1, 42, 8, 19]
najm, najw = mini_maks(dane)
print(f"Tablica: {dane} -> MIN: {najm}, MAX: {najw}")

10. Sortowanie bąbelkowe (Bubble Sort)

Klasyczne sortowanie przez prostą zamianę
Strona 173, Ćwiczenie 1

Treść zadania z podręcznika:

„Napisz i przetestuj program sortujący niemalejąco tablicę liczb całkowitych algorytmem sortowania bąbelkowego.”

Jak działa algorytm?

Sortowanie bąbelkowe to jeden z najbardziej poglądowych algorytmów porządkowania danych w miejscu:

  • Idea bąbelka: Przeglądamy tablicę od lewej do prawej i porównujemy pary sąsiednich elementów A[j] i A[j+1]. Jeśli element lewy jest większy od prawego, zamieniamy je miejscami.
  • Wypływanie na koniec: W wyniku pierwszego pełnego przebiegu największa liczba w tablicy „wypływa” na sam koniec (pod indeks $n-1$).
  • Skracanie zakresu: W kolejnym kroku badamy tablicę już tylko do przedostatniej pozycji, gdyż ostatni element ma już zagwarantowaną docelową pozycję.
  • Optymalizacja z flagą zamiany: Jeśli w danym przejściu pętli wewnętrznej nie dokonano żadnej zamiany elementów, tablica jest już w pełni posortowana i można natychmiast przerwać program.
Złożoność czasowa: $O(n^2)$ pesymistyczna i średnia, $O(n)$ w przypadku posortowanym
Złożoność pamięciowa: $O(1)$ (sortowanie w miejscu).
#include <iostream>

using namespace std;

void SortujBabelkowo(int A[], int n)
{
    int pom;
    for (int i = 1; i < n; i++)
    {
        for (int j = 0; j < n - i; j++)
        {
            if (A[j] > A[j + 1])
            {
                pom = A[j];
                A[j] = A[j + 1];
                A[j + 1] = pom;
            }
        }
    }
}

int main()
{
    const int N = 5;
    int A[N] = {6, 4, 9, 1, 5};
    SortujBabelkowo(A, N);
    cout << "Posortowana tablica: ";
    for (int i = 0; i < N; i++)
        cout << A[i] << " ";
    cout << endl;
    return 0;
}
def sortowanie_babelkowe(A):
    tab = list(A)
    n = len(tab)
    for i in range(1, n):
        zamiana = False
        for j in range(0, n - i):
            if tab[j] > tab[j + 1]:
                tab[j], tab[j + 1] = tab[j + 1], tab[j]
                zamiana = True
        if not zamiana:
            break
    return tab

liczby = [6, 4, 9, 1, 5]
print("Przed:", liczby)
print("Po:   ", sortowanie_babelkowe(liczby))
